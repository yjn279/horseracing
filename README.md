# 競馬オッズ補正システム

市場オッズから導出した確率分布を、ニューラルネットワークを用いて真の確率分布に補正するシステムです。

## 概要

競馬市場には「フェイバリット・ロングショットバイアス」という既知のバイアスが存在します：
- **フェイバリット（本命馬）**: 市場で過大評価される（実際の勝率より高いオッズ）
- **ロングショット（穴馬）**: 市場で過小評価される（実際の勝率より低いオッズ）

このシステムは、過去データから市場の歪みパターンを学習し、より正確な勝率予測を行います。

## 特徴

- **シンプル**: 1つのPythonファイル（200行以内）に全機能を実装
- **スマート**: ニューラルネットワークが市場バイアスを自動学習
- **エレガント**: 確率制約（合計=1、非負）を自然に満たす設計

## アーキテクチャ

### データ生成
合成データでフェイバリット・ロングショットバイアスを再現：
```
真の確率 → バイアス適用 → 市場確率
         ↓
    レース結果（1着馬）
```

### ニューラルネットワーク
```
市場確率 (n_horses,)
    ↓
Linear(n_horses, 64) + ReLU
    ↓
Linear(64, n_horses)
    ↓
Softmax（確率制約を保証）
    ↓
補正確率 (n_horses,)
```

### 評価指標
- **的中率**: 予測確率が最も高い馬の勝率
- **Log Loss**: 確率予測の精度（低いほど良い）
- **較正曲線**: 予測確率と実際の勝率の一致度
